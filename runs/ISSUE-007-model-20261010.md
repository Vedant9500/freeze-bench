Proposed block-vs-warn calibration (offline-deterministic):
- BLOCK (`severity="error"`, gate fails as today): keep exactly the current deterministic checks — empty list, non-string citation, bad URL syntax, unknown artifact ID, missing/non-file or out-of-root path, missing/invalid evidence label. No network in this path.
- WARN (`severity="warning"`, passes gate but flagged + confidence penalty, following `openlmlib/write_gate.py:161-172,227-244` precedent): add three offline-only checks in `validate_hypothesis_grounding`/`verify_citations`: (a) citation↔evidence linkage — every citation string (normalized) must occur in at least one `evidence[].source`, and every evidence item should map to ≥1 citation, else warn `unevidenced_citation`/`uncited_evidence`; (b) local content support — for `local_path`/`artifact` kinds, read bytes offline and compute lexical overlap / negation-contradiction (reuse `_tokenize`/`_claims_contradict` style from `write_gate.py:253-271` or claim-evidence cosine when embedder present); zero overlap or detected contradiction → warn + `adjust_confidence`-style −0.1, never block (paraphrase-safe); (c) URL entailment-without-probing — fabricated-but-well-formed URL with no quotation in any `evidence[].summary` → warn `unquoted_url`; actual HEAD/GET probing stays strictly opt-in (`OPENLMLIB_CHECK_CITATION_URLS=1` or `check_url_reachability=True`) and on probe failure emits warn by default, error only under an explicit `strict_reachability` flag, so default runs stay hermetic and deterministic.
- Coverage-count gaming fix: replace `citation_count>0` numerators (`evaluation.py:95-96,116,142-143`) with grounded counts — citations that are both `resolved` AND linkage/content-warn-free (or verifier verdict `supported`/`partially_supported`), capped at one credit per hypothesis/report (dedupe identical strings, `min(citations, slots)`), and surface both `citation_coverage_raw` (diagnostic) and `citation_coverage_grounded` (used by `_traceability_score`/`_quality_score`/`compare_workflows`); otherwise padding N irrelevant URLs/files/artifacts inflates the default-workflow recommendation threshold.
